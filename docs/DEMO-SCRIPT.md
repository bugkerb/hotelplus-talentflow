# Three-minute demo script

- 0:00-0:20: Introduce TalentFlow and the HR end-to-end flow.
- 0:20-0:50: Open Scraper, paste JD criteria, generate explainable shortlist, approve candidate.
- 0:50-1:30: Open AI Screener, paste/upload resume, show structured score and prescreen questions.
- 1:30-2:15: Open Tracker, search/filter and move candidate through controlled stages.
- 2:15-2:45: Open Scheduler, create Google Meet-compatible meeting and show conflict check.
- 2:45-3:00: Explain domain separation, security controls, deterministic AI harness, 100% business-logic coverage, and CI.
